JavaScript Phase 1 — Beginner Study & Hands-On Guide

Audience: Complete programming beginner

Goal: Learn the core JavaScript concepts in 7 days through explanation, coding practice, exercises and a small hands-on project.

Next goal: After Phase 1, move into TypeScript and then Playwright automation.

Contents 1. How to use this guide 2. Basic setup 3. Variables 4. Data Types 5. Operators 6. Conditions 7. Loops 8. Functions 9. Arrays 10. Objects 11. Destructuring & Spread 12. Modules 13. Error Handling 14. Promises & async/await 15. Seven-Day Plan 16. Week-End Project 17. Completion Checklist

1. How to use this guide

This guide is designed for someone starting programming from zero. Do not try to memorize syntax. The objective is to understand what the code is doing and then practice it.

  • Read: Understand the concept and example.
  • Type: Type the example manually instead of copy/paste whenever possible.
  • Change: Modify at least one value and predict the output.
  • Practice: Complete the day's tasks independently.
  • Explain: At the end of each day, explain the concept in your own words.
7-day target: By the end of the week, you should be able to create small JavaScript programs using variables, conditions, loops, functions, arrays, objects, modules, error handling and async/await.

2. Basic setup

You need a code editor and a JavaScript runtime. A simple setup is Visual Studio Code + Node.js. Create a folder such as javascript-phase1 and place your practice files there.

2.1 Your first program

console.log("Hello, world!");

Run the file with Node.js. console.log() prints information to the terminal.

2.2 First practice

console.log("My name is ___");
console.log("I am learning JavaScript");
console.log(10 + 20);

3. Variables — storing information

A variable is a named place/reference used by your program to work with a value.

3.1 const

const name = "Anu";
console.log(name);

Use const when you do not plan to reassign the variable.

3.2 let

let age = 20;
age = 21;
console.log(age);

Use let when the variable needs to be reassigned.

3.3 Declaration and assignment

let score; // declaration
score = 100; // assignment
let marks = 90; // declaration + initial value

3.4 undefined and null

let result;
console.log(result); // undefined

let selectedUser = null;
console.log(selectedUser); // null

3.5 Naming

const firstName = "Anu";
let totalMarks = 95;
const isPassed = true;

Use meaningful names. Prefer camelCase such as firstName, totalMarks and isPassed.

4. Data Types

A value has a type. JavaScript's most important beginner types are string, number, boolean, undefined, null, object and array.

4.1 String

const name = "Anu";
const city = 'Chennai';
console.log(name);
console.log(city);

4.2 Number

const age = 22;
const price = 199.50;

4.3 Boolean

const isLoggedIn = true;
const isAdmin = false;

4.4 typeof

console.log(typeof "Hello"); // string
console.log(typeof 25); // number
console.log(typeof true); // boolean
console.log(typeof undefined); // undefined

4.5 Arrays

const fruits = ["Apple", "Mango", "Orange"];
console.log(fruits[0]); // Apple
console.log(fruits.length); // 3

4.6 Objects

const student = {
  name: "Anu",
  age: 22,
  city: "Chennai"
};

console.log(student.name);
console.log(student.age);

5. Operators

5.1 Arithmetic

const a = 10;
const b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);

5.2 Comparison

console.log(10 > 5); // true
console.log(10 < 5); // false
console.log(10 === 10); // true
console.log(10 === "10"); // false
console.log(10 !== 5); // true

Use === for equality while learning. It checks both value and type.

5.3 Logical operators

const age = 25;
const hasId = true;

console.log(age >= 18 && hasId);
console.log(age < 18 || hasId);
console.log(!hasId);

6. Conditions

6.1 if / else

const marks = 75;

if (marks >= 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}

6.2 else if

const score = 85;

if (score >= 90) {
  console.log("Excellent");
} else if (score >= 60) {
  console.log("Good");
} else {
  console.log("Needs improvement");
}

6.3 switch

const day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of week");
    break;
  case "Friday":
    console.log("Almost weekend");
    break;
  default:
    console.log("Normal day");
}

7. Loops

Loops repeat code. Start with the classic for loop, then learn while and for...of.

7.1 for

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

7.2 while

let count = 1;

while (count <= 5) {
  console.log(count);
  count++;
}

7.3 for...of

const fruits = ["Apple", "Mango", "Orange"];

for (const fruit of fruits) {
  console.log(fruit);
}

7.4 break and continue

for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}

8. Functions — reusable blocks of code

A function is a reusable piece of code that can receive input, perform work and return an output.

8.1 Function declaration

function add(a, b) {
  return a + b;
}

const result = add(10, 20);
console.log(result);

8.2 Parameters and arguments

function greet(name) {
  console.log("Hello " + name);
}

greet("Anu");
greet("Priya");

The name inside the function definition is a parameter. The actual value passed to the function is an argument.

8.3 Return value

function calculateTotal(price, quantity) {
  return price * quantity;
}

const total = calculateTotal(100, 3);
console.log(total);

8.4 Default parameter

function greet(name = "Guest") {
  return `Hello ${name}`;
}

console.log(greet());
console.log(greet("Anu"));

8.5 Function expression

const multiply = function (a, b) {
  return a * b;
};

console.log(multiply(4, 5));

8.6 Arrow function

const add = (a, b) => {
  return a + b;
};

const square = (n) => n * n;
console.log(square(5));

8.7 Functions calling other functions

function double(n) {
  return n * 2;
}

function processNumber(n) {
  return double(n) + 10;
}

console.log(processNumber(5)); // 20
This is important because real applications are built by combining many small functions.

9. Arrays

An array stores multiple values in an ordered collection. Indexes start at 0.

9.1 Basic operations

const numbers = [10, 20, 30];

numbers.push(40);
console.log(numbers);

numbers.pop();
console.log(numbers);

console.log(numbers.includes(20));

9.2 forEach

const numbers = [10, 20, 30];

numbers.forEach((number) => {
  console.log(number);
});

9.3 map

const numbers = [1, 2, 3];
const doubled = numbers.map((number) => number * 2);
console.log(doubled); // [2, 4, 6]

9.4 filter

const numbers = [10, 15, 20, 25, 30];

const evenNumbers = numbers.filter((number) => {
  return number % 2 === 0;
});

console.log(evenNumbers);

9.5 find

const users = [
  { id: 1, name: "Anu" },
  { id: 2, name: "Priya" }
];

const user = users.find((item) => item.id === 2);
console.log(user);

9.6 reduce

const numbers = [10, 20, 30];

const total = numbers.reduce((sum, number) => {
  return sum + number;
}, 0);

console.log(total); // 60

10. Objects

Objects group related information together using key-value pairs.

10.1 Creating an object

const student = {
  name: "Anu",
  age: 22,
  course: "JavaScript"
};

console.log(student.name);
console.log(student.course);

10.2 Updating and adding properties

student.age = 23;
student.city = "Chennai";
console.log(student);

10.3 Nested objects

const employee = {
  name: "Anu",
  address: {
    city: "Chennai",
    country: "India"
  }
};

console.log(employee.address.city);

10.4 Object method

const user = {
  name: "Anu",

  greet() {
    return `Hello ${this.name}`;
  }
};

console.log(user.greet());

10.5 Array of objects

const employees = [
  { id: 1, name: "Anu", active: true },
  { id: 2, name: "Priya", active: false }
];

const activeEmployees = employees.filter(
  (employee) => employee.active
);

console.log(activeEmployees);

11. Destructuring and Spread

11.1 Object destructuring

const user = {
  name: "Anu",
  age: 22
};

const { name, age } = user;

console.log(name);
console.log(age);

11.2 Array destructuring

const colors = ["Red", "Blue", "Green"];

const [first, second] = colors;

console.log(first);
console.log(second);

11.3 Spread with arrays

const first = [1, 2, 3];
const second = [4, 5, 6];

const combined = [...first, ...second];
console.log(combined);

11.4 Spread with objects

const user = {
  name: "Anu",
  age: 22
};

const updatedUser = {
  ...user,
  age: 23
};

console.log(updatedUser);

12. Modules — splitting code into files

As programs become larger, you should not put everything in one file. Modules let you export code from one file and import it into another.

12.1 Export

// math.js
export function add(a, b) {
  return a + b;
}

export function multiply(a, b) {
  return a * b;
}

12.2 Import

// app.js
import { add, multiply } from "./math.js";

console.log(add(10, 20));
console.log(multiply(4, 5));

The same idea will later be used heavily in TypeScript projects.

13. Error Handling

13.1 try/catch

try {
  const value = JSON.parse("invalid");
  console.log(value);
} catch (error) {
  console.log("Something went wrong");
}

13.2 throw

function divide(a, b) {
  if (b === 0) {
    throw new Error("Cannot divide by zero");
  }

  return a / b;
}

try {
  console.log(divide(10, 0));
} catch (error) {
  console.log(error.message);
}

Error handling helps programs fail in a controlled and understandable way.

14. Promises and async/await

Some operations take time, such as reading data, calling an API or waiting for a browser action. JavaScript represents these future results using Promises.

14.1 Promise

const promise = new Promise((resolve) => {
  setTimeout(() => {
    resolve("Finished");
  }, 1000);
});

promise.then((result) => {
  console.log(result);
});

14.2 async function

async function getMessage() {
  return "Hello";
}

getMessage().then((message) => {
  console.log(message);
});

14.3 await

async function run() {
  const message = await getMessage();
  console.log(message);
}

run();

14.4 async error handling

async function run() {
  try {
    const message = await getMessage();
    console.log(message);
  } catch (error) {
    console.log("Failed:", error);
  }
}
Important: Do not rush past async/await. It will be one of the most important concepts when you later learn Playwright.

15. Seven-Day Hands-On Plan

The goal is to finish Phase 1 this week. Each day should include approximately 2–3 hours: 45–60 minutes learning, 60–90 minutes coding, and 15–30 minutes revision.

Day 1 — Variables + Data Types

Create 15 variables using const/let. Practice string, number, boolean, null, undefined, arrays and objects. Use typeof on at least 15 values. Build a simple personal profile program that prints name, age, city, learning status and three hobbies.

Day 2 — Operators + Conditions

Practice arithmetic, comparison, ===, !==, &&, || and !. Write at least 10 if/else examples. Build a marks calculator: input marks and print Excellent/Good/Pass/Fail. Add a simple age eligibility check.

Day 3 — Loops

Write for, while and for...of loops. Practice break and continue. Solve at least 8 loop problems. Print 1–50, even numbers, multiplication table of 5, sum of numbers 1–100, and values from an array.

Day 4 — Functions

Write at least 12 functions. Practice parameters, return, defaults, function expressions and arrow functions. Build a calculator with add, subtract, multiply and divide functions. Add validation for division by zero.

Day 5 — Arrays + Objects

Practice push, pop, includes, forEach, map, filter, find and reduce. Create arrays of objects. Create an employee/student data set. Find a person, filter active people, list names, calculate totals and search by a property.

Day 6 — Destructuring + Modules + Errors

Practice object/array destructuring, spread, import/export, try/catch and throw. Split your calculator/data project into multiple files. Add validation and meaningful error messages.

Day 7 — Promises + async/await + Revision

Create and consume Promises. Practice async/await and try/catch. Revisit all previous topics. Complete the mini project below. Then explain every major line of your own code without looking at the guide.

16. Week-End Hands-On Project

Project: Student Management Console

Build a small JavaScript program that manages student information. Do not copy a complete solution from the internet. Build it feature by feature.

const students = [
  {
    id: 1,
    name: "Anu",
    age: 22,
    marks: 85,
    active: true,
    skills: ["HTML", "JavaScript"]
  },
  {
    id: 2,
    name: "Priya",
    age: 23,
    marks: 72,
    active: true,
    skills: ["JavaScript"]
  }
];

Required functions

  1. findStudentById(id)
  2. getActiveStudents()
  3. getStudentNames()
  4. getAverageMarks()
  5. findStudentsAboveMarks(mark)
  6. hasSkill(student, skill)
  7. addStudent(student)
  8. removeStudent(id)

Also

  • Use map, filter, find and reduce.
  • Use destructuring at least once.
  • Put reusable functions in a separate module.
  • Add try/catch and throw for invalid input.
  • Create one async function that simulates loading students.
The project should be your proof that you understand Phase 1. It does not need a user interface; a clean terminal program is enough.

17. Phase 1 Completion Checklist

Before moving to TypeScript, you should be able to do these without following a tutorial line by line.

  • Create variables using const and let and explain when to use each.
  • Explain string, number, boolean, null, undefined, arrays and objects.
  • Use arithmetic, comparison and logical operators.
  • Write if/else and switch conditions.
  • Write for, while and for...of loops.
  • Create functions with parameters and return values.
  • Use arrow functions.
  • Use array methods: forEach, map, filter, find and reduce.
  • Create and manipulate objects and nested objects.
  • Use destructuring and spread syntax.
  • Create modules using export and import.
  • Handle errors with try/catch and throw.
  • Understand what a Promise is.
  • Write basic async/await code.
  • Build the Student Management Console without copying a full solution.
